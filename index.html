Tugas 1 — Fetch-Decode-Execute Cycle

Analisis Siklus Fetch-Decode-Execute

Fetch-Decode-Execute merupakan siklus kerja dasar CPU dalam menjalankan sebuah instruksi. CPU akan mengambil instruksi dari memori, menerjemahkan instruksi tersebut, kemudian menjalankannya.

1. FETCH CPU mengambil instruksi dari memori.
2. DECODE CPU menerjemahkan instruksi yang diperoleh.
3. EXECUTE CPU menjalankan instruksi tersebut.

Contoh: Penjumlahan Dua Bilangan

Misalnya terdapat instruksi untuk menjumlahkan angka 5 dan 3. CPU akan melakukan proses sebagai berikut:

  1. Fetch: CPU mengambil instruksi penjumlahan dari memori.
  2. Decode: CPU menerjemahkan instruksi bahwa operasi yang harus dilakukan adalah penjumlahan.
  3. Execute: ALU melakukan operasi 5 + 3.
  4. Hasil: CPU memperoleh hasil 8 dan menyimpannya pada register atau memori sesuai instruksi.
Kesimpulan: Siklus Fetch-Decode-Execute memungkinkan CPU menjalankan instruksi secara berurutan sehingga program dapat bekerja sesuai perintah yang diberikan.

Tugas 2 — Perbandingan SSD dan HDD

Perbandingan Karakteristik

Karakteristik SSD HDD
Teknologi Flash memory Piringan magnetik
Kecepatan Lebih cepat Lebih lambat
Ketahanan terhadap guncangan Lebih tahan Lebih rentan
Suara Hampir tidak bersuara Dapat menghasilkan suara
Konsumsi daya Relatif lebih rendah Relatif lebih tinggi
Harga per kapasitas Lebih mahal Lebih murah

Evaluasi untuk Laptop Mahasiswa yang Sering Dibawa

Untuk laptop mahasiswa yang memiliki mobilitas tinggi, SSD lebih sesuai digunakan dibandingkan HDD. SSD tidak menggunakan komponen mekanis yang bergerak sehingga lebih tahan terhadap guncangan ketika laptop dibawa berpindah tempat.

Selain itu, SSD memiliki kecepatan baca dan tulis yang lebih tinggi sehingga proses booting sistem operasi, membuka aplikasi, menjalankan program, dan mengakses file dapat dilakukan dengan lebih cepat.

Kesimpulan: SSD lebih sesuai untuk laptop mahasiswa dengan mobilitas tinggi karena memiliki kecepatan yang tinggi, lebih tahan terhadap guncangan, dan mendukung penggunaan laptop yang lebih praktis.

Tugas 3 — Sistem Rekam Medis Elektronik Rumah Sakit

Studi Kasus

Sebuah rumah sakit membutuhkan sistem rekam medis elektronik yang dapat diakses dengan cepat oleh puluhan tenaga medis secara bersamaan. Sistem juga harus mampu menjaga data agar tidak hilang.

Spesifikasi CPU yang Sesuai

CPU dengan beberapa core dan thread diperlukan agar server dapat menangani banyak proses secara bersamaan. CPU multi-core dapat membantu menjalankan permintaan dari banyak pengguna tanpa bergantung pada satu proses saja.

Untuk sistem rumah sakit, CPU kelas server dengan jumlah core yang memadai dapat digunakan agar sistem mampu menangani database, aplikasi rekam medis, autentikasi pengguna, dan proses lainnya secara bersamaan.

Spesifikasi Storage yang Sesuai

  • Menggunakan SSD untuk mempercepat akses database.
  • Menggunakan kapasitas yang disesuaikan dengan jumlah data.
  • Menggunakan RAID untuk meningkatkan ketersediaan data.
  • Melakukan backup data secara rutin.
  • Menggunakan media penyimpanan tambahan untuk cadangan.

Alasan Pemilihan

SSD cocok digunakan karena sistem rekam medis membutuhkan akses data yang cepat. Database rumah sakit dapat berisi banyak data pasien sehingga kecepatan penyimpanan akan berpengaruh terhadap respons sistem.

Selain performa, keamanan data juga sangat penting. Penggunaan RAID dan sistem backup dapat membantu mengurangi risiko kehilangan data apabila terjadi kerusakan pada salah satu perangkat penyimpanan.

Kesimpulan: Sistem rekam medis elektronik sebaiknya menggunakan CPU multi-core kelas server dan penyimpanan SSD yang didukung RAID serta backup berkala. Kombinasi tersebut dapat mendukung akses banyak pengguna sekaligus dan meningkatkan perlindungan terhadap data.

Analisis Kesesuaian untuk Mahasiswa Sistem Informasi

Advan WorkPlus Ryzen 5 memiliki spesifikasi yang sesuai untuk menunjang aktivitas perkuliahan mahasiswa Sistem Informasi. Prosesor AMD Ryzen 5 6600H memiliki 6 core dan 12 thread sehingga dapat mendukung aktivitas multitasking seperti menjalankan browser, aplikasi perkantoran, dan aplikasi pemrograman secara bersamaan.

Penyimpanan SSD NVMe 512 GB memiliki kecepatan akses data yang tinggi sehingga dapat membantu mempercepat proses booting, membuka aplikasi, menjalankan program, dan mengakses file.

Laptop ini dapat digunakan untuk berbagai kegiatan mahasiswa Sistem Informasi seperti pemrograman, pengolahan data, penggunaan database, pembuatan dokumen, browsing, dan kegiatan perkuliahan lainnya.

GPU AMD Radeon 660M terintegrasi juga dapat digunakan untuk kebutuhan desain ringan. Namun, untuk pekerjaan grafis atau rendering yang sangat berat, GPU terintegrasi memiliki keterbatasan dibandingkan laptop dengan GPU dedicated.

Kesimpulan: Advan WorkPlus Ryzen 5 dengan Ryzen 5 6600H, RAM 16 GB, dan SSD NVMe 512 GB memiliki spesifikasi yang sesuai untuk menunjang aktivitas mahasiswa Sistem Informasi, terutama pemrograman, pengolahan data, database, multitasking, dan kebutuhan perkuliahan sehari-hari.
